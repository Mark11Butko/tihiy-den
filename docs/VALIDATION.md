освобождение замка после ошибки; повтор замены файла при временной блокировке чтением Rainmeter; атомарная запись и сохранение старого файла при сбое;
старый и повреждённый конфиг; страницы задач и инструментов; сохранение четвёртой
котировки при сбое источника; ближайшее событие на невидимой странице;
кавычки и переносы в задачах; пустая погода; шестинедельный месяц; пустой,
нулевой и одноточечный график; сохранение центов в крупных котировках; отсутствие подмены периода; ночное событие;
частичный сбой календарей; привязка кеша к ссылке, а не позиции;

шрифта и не содержит InputText / `$UserInput$`. Пользовательский ввод проходит
через отдельное окно и не становится строкой команды Rainmeter.

Проверены компиляция Python, `git diff --check` и синтаксис PowerShell-установщика.
CI добавлен в `.github/workflows/tests.yml`: Windows, Python 3.10 и 3.13.

## Ограничения и следующий ручной прогон

- Google — чтение iCal, не OAuth; Google Tasks не подключён. Задачи локальные.

- Для валют нет внутридневной серии: 24Ч показывает «Нет данных», не чужой период.
- Внешние API могут ограничивать запросы и менять доступность.
- После установки проверить реальные обои, DPI 100/125/150%, два монитора,
  сон/пробуждение, перемещение окна и личную ссылку Google.
- Эти проверки подтверждают указанные сценарии, а не полное отсутствие любых багов.
